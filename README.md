# reddit-portfolio

> Ravikesh — Reddit Growth for Startups Portfolio

A Reddit-styled portfolio designed to convert startup founders into trial clients for a one-month Reddit engagement.

## Features
- **Reddit Native Visual Language**: Orange accents (`#ff4500`), vote columns with interactive live score counters, Reddit flairs, and light/dark theme.
- **Pinned Hero Post**: Direct founder voice (*"Work with me for a month. Then judge."*) with single clear primary CTA above the fold.
- **How a Month Works**: 4-week engagement framework (Research, First Engagement, Community & Content, Review with Numbers).
- **Who This Is For**: SaaS, AI tools, Creator products, and Founders stuck on Reddit.
- **Dedicated Case Studies**:
  - `Vilva.ai`: 1,557 organic referral sessions in 30 days.
  - `Creator Economy Startup (Stealth)`: 340+ creator trial users across 4 communities.
  - `Oskar (Solo Founder)`: From 1 karma to 1,420 karma and first paying subscribers.
  - `CreatorsThatSpark`: Building `r/CreatorsThatSpark` to 1,240+ members with $0 ad spend.
- **Proof & Visual Assets**: Custom SVG analytics charts, karma verification dashboards, and community metric cards in `/assets/`.
- **Zero Build Step**: Standalone static HTML/CSS/JS with zero external dependencies.
